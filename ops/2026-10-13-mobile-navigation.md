# Mobile navigation

The shared responsive navigation shows a top-right icon-only hamburger button below768px. Clicking opens the existing links in a dark dropdown, with the existing active-tool accent. At768px and wider links remain visible in a row. The wrapper is applied to the four English tool pages, six translated reader/invert pages and existing blog headers. The PDF Dark brand is visible at all widths. Existing language controls sit outside the tool menu: a separate globe button on mobile, full language name on desktop. FAQ shortcuts are removed from header navigation; FAQ page content remains. No URL, keyword mapping or page content change.

Accessibility and interaction:44px minimum button and direct-link touch targets, aria-expanded/aria-controls, semantic nav and ordinary anchors. Escape closes and restores trigger focus; outside click, focus moving outside, link selection and crossing the desktop breakpoint close the dropdown. Opening the language selector closes the tool menu and vice versa; language controls support outside-click/Escape dismissal. Navigation links are server-rendered in one list, avoiding duplicate links and keeping them present in HTML.

Validation: scoped lint and TypeScript plus isolated production build passed. Screenshot/test harness artifacts are outside the checkout under `/workspace/pdf-dark-browser-tests/navigation/`.
